07 · a condensed view of ARCHITECTURE.md15 specs · 6 hooks · 5 steering files · 304 [kiro] commits
Kiro did the reading at build time with two agents that cannot see each other. Code gates what is published: six checks on every note (structure, in the page, ownership, note fidelity, contrast, time-of-ink), and the catalog-gate Kiro hook refuses an unverified write. A Kiro agent supplied the word cuts and stroke review the gate checks; the review record is signed by the builder's agent. The browser plays back the bundle and runs no model.
